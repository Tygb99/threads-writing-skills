# Threads 줄바꿈

## 언제 쓰는가

Threads 본문, 자답, 답글을 쓰거나 고칠 때 사용한다. 한 줄짜리 짧은 답글은 예외로 둔다. Instagram, X, 블로그 문안에는 적용하지 않는다.

## 핵심 규칙

- 한 줄 목표는 25자, 상한은 40자다. 글자 수에서 줄바꿈은 제외한다.
- 문단은 빈 줄 하나로 나누고, 최대 4줄로 둔다. 1~2줄을 권장한다.
- 연결어미 뒤 절 경계 쉼표에서 줄을 바꾼다. 숫자, 나열, 짧은 동격의 쉼표는 줄 중간에 둔다.
- 문장 끝 마침표는 생략한다. URL, 수치, 버전, 파일명 안의 점은 보존한다.
- 해시태그는 붙이지 않는다. 꼭 필요한 경우에도 마지막 단독 문단에 두고 자답글에는 붙이지 않는다.

## 적용 절차

1. 내용을 먼저 완성하고 문단을 나눈다. 생각 하나를 문단 하나에 담는다.
2. 40자를 넘는 줄을 찾아 절 경계 쉼표에서 끊는다.
3. 쉼표가 나열이나 숫자를 잇는지 확인하고 기계적으로 끊지 않는다.
4. 문장 끝 마침표와 해시태그를 현재 규칙에 맞게 정리한다.
5. 검사기를 실행하고 판단 보류 후보는 문맥으로 확인한다.

## 첫 문단 지침

첫 문단은 1~2줄을 권장한다. 첫 줄은 문장 종결어미로 끝내지 않는 미완결 형태를 권장하고, 숫자와 따옴표 포함 여부를 확인한다. 첫 문단의 주어가 사건인지 작업물인지는 사람이 정한다.

사건형 첫 문단 조회 중앙값은 940, 작업물형은 207이었다(129건 대조). 이 수치는 방향을 잡는 참고값이지 자동 판정 규칙이 아니다.

## 검사기 사용법

스크립트는 인자로 받은 파일 하나 또는 표준입력만 읽으며 파일을 탐색하지 않는다. 옵션, 출력 항목, 상수, 종료 코드는 각 검사기의 `--help`를 정본으로 삼는다.

```bash
python3 scripts/check_linebreaks.py draft.txt
cat draft.txt | python3 scripts/check_linebreaks.py
python3 scripts/check_linebreaks.py draft.txt --json
python3 scripts/check_first_paragraph.py draft.txt
python3 scripts/check_first_paragraph.py draft.txt --json
```

줄바꿈 검사기는 40자 초과, 4줄 초과 문단, 해시태그 위치를 위반으로 보고하고 줄 길이·문단 길이·줄 끝 분포와 쉼표 판단 보류 후보를 표시한다. 위반 없음은 exit 0, 위반 또는 빈 입력은 exit 1이다. 첫 문단 검사기는 첫 문단 3줄 이상만 exit 1로 보고한다.

## 완성 예시

```
오늘 아침 배포가 두 번 실패했고,
원인은 환경변수 하나였다

고치는 데 3분, 찾는 데 2시간

값을 확인하니 공백 하나가 남아 있었다
다음 배포부터는 시작 전에 검사한다
```

## 알아둘 것

- Threads 인라인 답글창에서 Enter는 줄바꿈이 아니라 즉시 게시다. 여러 줄은 확장 작성창이나 Shift+Enter를 사용한다.
- 본문, 자답, 답글에 같은 줄바꿈 규칙을 적용한다.
- 줄바꿈을 고친 뒤에는 문자 단위로 원문과 대조한다.
