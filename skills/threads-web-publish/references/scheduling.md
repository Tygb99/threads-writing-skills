# 예약과 카드

예약 설정·조회·수정, 링크 카드와 인용카드의 저장 조건을 다룬다.
Aside 앱과 대상 Threads 계정의 로그인이 필요하다.
`aside guide`를 읽고 `aside exec`으로 위임하며, 직접 DOM을 확인할 때만 `aside guide repl`을 읽고 REPL을 쓴다.
정본 텍스트·첨부·alt의 절대경로와 요청한 KST 시각을 [위임 양식](aside-setup.md)에 넣는다.
작업 중 새로고침하지 않고 확인창은 `취소`로 닫아 편집 상태를 유지한다.
예약·수정 저장 전에는 각 칸을 정본과 문자 단위로 대조한다.

## 시각과 중복 확인

1. 행동 직전 `TZ=Asia/Seoul date`로 현재 KST 시각을 확인한다.
2. 프로필 최신 글과 새 글 작성창의 `임시 저장본` 예약 목록을 읽는다.
3. 발행 간격은 **기본 2시간이며 사용자 지시가 우선**이다. 가장 늦은 발행·예약 시각에서 2시간 이후로 배치한다.
4. 사용자가 “게시해”라고 명시하면 그 1회는 간격 예외다. 다음 글의 기본값은 바꾸지 않는다.
5. 같은 첫 줄의 발행본이 있으면 게시하지 말고 보고한다. 같은 첫 줄의 예약본이 있으면 요청한 그 예약본인지 확인하며 새 항목을 중복 생성하지 않는다.

## 예약 설정

1. 작성창 우측 상단 `··· → 예약...`을 연다. `게시물 옵션`은 답글 권한 메뉴이므로 예약에 쓰지 않는다.
2. 달력에서 연·월·일을 확인해 날짜를 고른다.
3. 새 snapshot에서 확인한 예약 패널 안의 시·분 입력칸에 `locator.fill()`로 입력한다. 24시간제이며 AM/PM 전환으로 해석하지 않는다.

```javascript
await schedulePanel1.locator('input[placeholder="hh"]').fill('18');
await schedulePanel1.locator('input[placeholder="mm"]').fill('04');
console.log(await schedulePanel1.locator('input[placeholder="hh"]').inputValue());
console.log(await schedulePanel1.locator('input[placeholder="mm"]').inputValue());
```

4. 두 값이 목표와 같은지 확인하고 `완료`를 누른다. 시간칸에 삼중 클릭·타이핑으로 값을 넣지 않는다.
5. “게시 예정” 배너의 날짜·시각·GMT+9를 목표 KST와 대조한다. 배너의 오후 6:04는 입력값 18:04다.
6. 현재 작성창 아래 버튼이 `예약`인지 확인한다. 모든 칸·첨부·alt를 대조하고 원치 않는 링크 카드를 마지막으로 제거한 뒤 누른다.
7. 새 snapshot에서 작성창 소멸을 확인한다. 아래 경로로 목록을 다시 열어 첫 줄·예약 시각·답글 수를 확인한다.

## 예약본 조회와 수정

예약 글은 **새 글 작성창의 `임시 저장본` 아이콘**에서 찾는다.
아이콘 자체의 텍스트가 비어 있으므로 `svg[aria-label="임시 저장본"]`를 가진 버튼을 현재 작성창 범위에서 찾는다.
프로필 피드나 설정 페이지에서 예약 목록을 찾지 않는다.

1. 목록을 스크롤하며 눈으로 항목 수를 센다. 컨테이너 `innerText`에는 같은 항목이 중복되므로 문자열 출현 횟수를 개수로 쓰지 않는다.
2. 해당 첫 줄과 예정 시각을 확인해 연다. 예약본 편집의 하단 버튼은 `업데이트`다.
3. 본문 수정·`스레드에 추가`·시각 변경을 수행한다. 시간 변경도 `··· → 예약... → fill() → 완료` 순서다.
4. 변경한 칸과 기존 칸을 모두 문자 대조한다. 이미지·alt·예약 시각이 유지됐는지 확인한다.
5. 원치 않는 링크 카드를 다시 제거하고 `업데이트`한다.
6. 다시 열어 변경 내용·시각을 확인한다. 더 편집할 때 뜨는 “예약된 게시물을 업데이트하시겠어요?” 확인창에서는 `취소`로 돌아간다.

### 예약 초안의 alt만 바꾸기

alt 입력의 `완료`만으로는 예약본 저장이 끝나지 않는다.
alt만 변경해서 `업데이트`가 비활성이면 본문 끝에 임시 문자 한 개를 넣고 저장한다.
같은 예약본을 다시 열어 임시 문자를 제거하고 재저장한다.
본문·`img.alt` 또는 영상 `aria-label`·KST 예정 시각을 다시 읽어 대조한다.
alt 패널도 입력 전에 포커스를 확인하며 모든 첨부를 각각 확인한다.

## 예약 가능 여부

| 작성창 상태 | 예약 | 저장·발행 처리 |
|---|---|---|
| 텍스트, 사진 또는 일반 링크 미리보기 | 가능 | 시각 설정 후 예약 목록에서 확인한다. |
| Threads 인용카드 | 불가 | 발행 시각에 카드를 조립하고 게시한다. |
| 텍스트 첨부(장문 카드) | 불가 | 첨부까지 임시 저장하고 발행 시각에 열어 게시한다. |

인용카드가 있으면 `예약...`이나 예약본 `업데이트`가 비활성일 수 있다.
텍스트 첨부는 예약 항목 자체가 사라질 수 있다.
메뉴의 존재만 보지 말고 `aria-disabled`와 항목 유무를 확인한다. 자답글 칸의 인용카드도 예약을 막는다.
공식 API에는 예약 발행 기능이 없다. 이 스킬은 웹의 예약을 사용한다.
예약할 수 없는 조합은 임시 저장 또는 요청한 시점의 게시로 구분해 보고한다.
미래에 실행할 별도 작업이 실제로 설정되지 않았다면 “예약 완료”라고 말하지 않는다.

## 링크 미리보기와 인용카드

| 확인 항목 | 일반 링크 미리보기 | Threads 인용카드 |
|---|---|---|
| URL | 일반 URL 또는 게시물 permalink | 공유 UI에서 얻은 share URL |
| 카드 내용 | 사이트 이름·대표 이미지 | 원글 본문·첨부 |
| 카드의 제거 X | 있음 | 없음 |
| 본문 URL | 남음 | 카드로 바뀌어 사라짐 |
| 임시 저장 재열람 | 제거했어도 재생성될 수 있음 | 보존되지 않음 |
| 같은 칸의 이미지 | 가능 | 양립 불가 |

### 링크 카드

`CLAUDE.md`처럼 도메인으로 인식되는 파일명도 링크와 카드를 만든다.
카드의 X는 카드만 제거하며 본문 링크 텍스트는 남긴다.
링크 자체가 원치 않는 형태라면 사용자 의도에 맞게 문안을 수정하고 다시 대조한다.

URL이 남아 있는 임시 저장본은 다시 열 때마다 링크 카드를 만들 수 있다.
**카드 제거는 마지막 `예약`·`업데이트`·`게시` 직전에 한다.**
재확인을 위해 초안을 열었다면 마지막 저장 전에 카드 상태를 다시 점검한다.
발행 후 수정창에서 보이는 미리보기만으로 실제 카드가 붙었다고 판단하지 않는다. 발행 페이지와 API를 확인한다.

### 인용카드 만들기

원글의 공유 UI에서 받은 `https://www.threads.com/share/…/` 형태 URL로 카드를 만든다.
`https://www.threads.com/@계정/post/…` 형태 permalink는 일반 링크 미리보기이며 기다려도 인용카드가 되지 않는다.
원글의 리포스트 버튼에서 `인용하기`를 선택해 인용 작성창으로 들어갈 수도 있다.

답글을 인용할 때는 답글 공유 아이콘으로 연 **전송 시트 하단 `링크 복사`**를 사용한다.
메뉴의 같은 이름 항목은 부모 글을 가리킬 수 있다.
실제 locator 클릭으로 링크를 복사하고, 카드 생성 뒤 본문이 인용하려던 답글과 같은지 확인한다.
URL을 읽을 수 없으면 사용자가 제공한 share URL을 사용하며 링크 형식을 추측하지 않는다.

이미지가 있는 칸에는 인용카드가 생기지 않는다. 둘 다 필요하면 칸을 나눈다.
이미 붙은 인용카드는 작성창에서 X로 제거할 수 없다.
예약이 필요해 카드를 빼야 한다면 정본과 첨부를 확보한 뒤 인용카드 없는 새 작성창으로 구성한다.

### 임시 저장 뒤 재개

임시 저장은 텍스트와 이미지를 보존하지만 인용카드를 보존하지 않는다.
따라서 인용카드는 게시 직전에 다시 붙이고 내용·대상 글을 확인한다.

장문 카드와 인용카드를 같이 쓰면 인용카드를 먼저 만든 뒤 텍스트 첨부를 추가한다.
반대 순서는 인용카드를 만들지 않는다. 임시 저장에서는 장문 카드만 남는다.
재개할 때는 첨부 정본을 확보하고 `텍스트 첨부 삭제 → 인용카드 생성 → 텍스트 첨부 재입력` 순서로 조립한다.
장문 카드는 10,000자 한도(개행 2자)이며 사진·GIF·설문·음악과 함께 쓸 수 없다.
텍스트 첨부 버튼은 `svg[aria-label="텍스트 첨부"]`, 입력칸은 `aria-placeholder="내용을 더 추가해보세요..."`로 구분한다.

초안 목록의 `임시 저장본 삭제`는 확인창 없이 지워진다. 요청된 삭제 대상의 첫 줄을 확인한 경우에만 누른다.

## 완료 보고

예약은 첫 줄·답글 수·KST 예정 시각·본문/alt 대조 결과를 보고한다.
발행된 permalink가 아직 없으면 예약본 식별 첫 줄을 쓰고 permalink는 미확인으로 둔다.
실제 발행 후에는 즉시 화면을 확인하고 +16분 [공식 API 검증](recovery.md#공식-api-확정-검증)으로 문자·미디어·alt를 확정한다.
24h·72h 성과 크론을 만들지 않는다.
