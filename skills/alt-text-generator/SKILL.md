# 이미지 대체 텍스트

## 언제 쓰는가

이미지를 올리며 alt, 대체 텍스트, 이미지 설명, 접근성 텍스트를 요청할 때 사용한다. 용도를 말하지 않으면 웹 접근성을 기본으로 한다.

## 원칙

- 핵심 정보부터 쓴다
- `사진`, `이미지`, `그림`으로 시작하지 않는다
- 웹 접근성은 약 125자, SNS와 블로그는 약 150자를 목표로 한다
- 보이는 사실만 쓴다. 인물의 감정·의도·정체를 추측하지 않는다
- 이미지 안의 글자는 생략하거나 바꾸지 않고 그대로 옮긴다
- Threads 카드 이미지는 카드 안 글자를 그대로 옮긴다
- 장식용이거나 본문과 중복되는 이미지는 `alt=""`를 권한다
- HTML 속성의 큰따옴표는 `&quot;`로 바꾼다

## 용도 판단

| 용도 | 길이 | 작성 기준 |
|---|---:|---|
| 웹 접근성 | 약 125자 | 객관적 사실, 핵심 사물·행동·맥락 |
| Threads·SNS | 약 150자 | 사실을 우선하고 분위기는 짧게 허용 |
| 블로그·SEO | 약 150자 | 주제어를 자연스럽게 포함하고 나열하지 않음 |

스크린샷·차트·인포그래픽은 웹 접근성 기준으로 쓴다. 사용자가 Threads나 블로그를 명시하면 해당 용도를 따른다.

## 출력 형식

설명 없이 다음 두 코드 블록을 모두 출력한다. 두 블록의 내용은 같아야 한다.

```
[한국어 alt 텍스트 한 줄]
```

```html
alt="[HTML 이스케이프한 같은 텍스트]"
```

장식용이면 첫 블록은 비어 있는 alt를 권한다고 쓰고, 두 번째 블록은 다음처럼 출력한다.

```html
alt=""
```

## 예시

### 풍경

```
주황빛 해질녘 바다, 수평선 위에 작은 어선 한 척
```

```html
alt="주황빛 해질녘 바다, 수평선 위에 작은 어선 한 척"
```

### 카드 이미지

이미지 안 문구가 `작은 습관이 큰 변화를 만든다`라면 다음처럼 글자를 그대로 옮긴다.

```
짙은 초록 배경의 카드, 중앙에 "작은 습관이 큰 변화를 만든다"라는 문구
```

```html
alt="짙은 초록 배경의 카드, 중앙에 &quot;작은 습관이 큰 변화를 만든다&quot;라는 문구"
```

### 장식 이미지

본문과 같은 내용을 반복하는 장식용 배경이면 빈 alt를 권한다.

```
빈 alt 권장
```

```html
alt=""
```

## 하지 말 것

- `사진입니다`, `이미지입니다`로 시작하지 않는다
- 아름답다, 멋지다처럼 주관적인 평가를 사실처럼 쓰지 않는다
- 키워드를 쉼표로 나열하지 않는다
- 보이지 않는 인물의 나이·성별·인종·감정을 단정하지 않는다
- 이미지의 글자를 요약하거나 임의로 고치지 않는다
- 같은 이미지에 선택지를 여러 개 늘어놓지 않는다
