# 브랜드 값 견본

이 파일을 같은 폴더의 `brand.local.md`로 복사하고 가짜 값을 사용자 값으로 바꾼다.
다른 폴더에 저장했다면 `fill_brand.py --brand /absolute/path/to/brand.local.md`로 지정한다.
파일은 UTF-8로 저장한다. 항목 이름과 백틱을 유지하며, 값 안의 세로줄은 `\|`로 쓴다.
값 안에 백틱이나 줄바꿈을 넣지 않는다.

| 항목 | 값 |
|---|---|
| 표시 이름 | `예시 브랜드` |
| 한 줄 소개 | `기록하는 사람` |
| 핸들 | `@sample.note` |
| 링크 | `example.com` |

## 마크 이미지

아래 언어 표시 없는 코드블록에 실제 존재하는 PNG 파일의 절대 경로를 한 줄로 적는다.
경로를 백틱·따옴표로 감싸거나 `~`로 줄이지 않는다. 확장자는 `.png`로 쓴다.

```
/absolute/path/to/brand-mark.png
```
